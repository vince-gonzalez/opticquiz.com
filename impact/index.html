THE IMPACT
ARCHIVE

OpticQuiz keeps no analytics on the people who use it. That is a deliberate choice, and it has a cost: without tracking, the project cannot show that it helps anyone.

So this page asks instead. Everything below was volunteered by a person who clicked a button, and every word published here was published because its author explicitly said it could be — and can be deleted by them at any time, with no account.

What this page is not.

It is not a testimonials wall and it is not a sample. The people who answer are self-selected, and self-report is weak evidence. It is published anyway, in full, including the answers that say no, this did not help — because a record you can check is worth more than a claim you have to trust. HOW THIS IS COLLECTED

The block that asks “did this help you?” appears on OpticQuiz tools. It is the same code everywhere — /assets/oq-feedback.js — and it works like this:

Nothing is sent until you press a button

There is no beacon on page load, no page-view record, no cookie, and no identifier of any kind. If you never click, the archive never learns you existed.

Two locks before anything is published

Your words appear here only if you ticked the publish box and a human then approved the record. Skip the box and your answer is only ever counted, never quoted.

Consent you can take back

Every submission returns a withdraw code. Entering it below deletes the record permanently — from the archive, from the counts, and from every future export. No account, no email, no reason required. Withdraw a record →

What is stored

Exactly the fields you filled in, plus the date at day precision (a timestamp to the second is a fingerprint; a date is a fact) and which tool you were using. No IP address is stored against a submission. An email is stored only if you typed one, is never published, and is never added to any list.

The one thing that touches your IP

To stop a script flooding the moderation queue, the server counts submissions per hour against a salted SHA-256 hash of the connection's IP. The hash cannot be reversed to an address, is never stored next to a submission, and is deleted when the hour ends. It is written down here because a privacy claim with an undisclosed exception is a lie. The code is public.
