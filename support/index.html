SUPPORT

Help for the Colorblind Corrector extension, the camera mode, and the rest of the OpticQuiz color-accessibility tools. Most answers are below; anything else, reach out and a real person replies.

Get help directly: open an issue at github.com/zengineco/opticquiz.com/issues — it's the fastest way to reach the developer, and it's public so others benefit. OpticQuiz is an independent, open-source project.

COLORBLIND CORRECTOR (EXTENSION)

It isn't changing colors on a page.

Make sure a mode other than Off is selected in the toolbar popup. A few pages — browser settings pages, the extension store itself, some PDF viewers — block extensions for security, so the filter can't run there. On a normal web page, pick Recommended and the whole page should recolor.

A page looks broken while a mode is on.

The correction applies one color filter to the page, which can shift elements that use fixed or sticky positioning (sticky headers, some modals). Switch the mode to Off to restore the page instantly. A per-element approach that avoids this is planned.

Which mode should I choose?

If you don't know your type, choose Recommended. Otherwise Deuteranopia (green-weak, most common), Protanopia (red-weak), or Tritanopia (blue-yellow). You can switch any time — and if you want to check your type, OpticQuiz has free color-vision tests.

Does it collect my data?

No. No network requests, no analytics, no account; only your chosen mode is stored locally. See the privacy policy.

CAMERA MODE

The camera won't start.

Your browser needs camera permission — when opticquiz.com/live asks, choose Allow. It works best in Chrome or Safari on a phone. Nothing from the camera is recorded or uploaded; the correction happens live on the device.

CHECKER, WIDGET & PACKAGES (DEVELOPERS)

How do I add the widget or use the packages?

Everything is on the developer platform page with copy-paste snippets — the one-line widget, the npm/pip packages, the API, the VS Code extension, and the GitHub Action.

Is any of this a legal accessibility audit?

No. These are screening and correction aids for one axis, color, and every page says so. They don't certify WCAG/ADA/EAA compliance, which covers far more than color. The method is published so its limits are documented.
